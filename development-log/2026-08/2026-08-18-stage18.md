## 🛠️ 完成内容详解

### 1. 📱 主页顶部栏极简瘦身与排版对齐 (`HomeScreen.kt`)
- **紧凑高度**: 顶部栏高度严格控制为 **50dp**，消除空间浪费，大幅释放首屏瀑布流笔记的可视面积；
- **极简品牌标题**: 标题设为 **18sp** 中粗体 `Lozify ▾`（带 `16dp` 下拉微标），与侧边栏抽屉的视觉意向呼应；
- **精致图标比例**: 汉堡菜单 `☰` 与搜索图标 `🔍` 调整为 `20dp~22dp` 的精致比例，色彩统一为 `#333333` / `#555555`。

### 2. 📑 笔记卡片视觉与排版 1:1 对标 (`NoteCard.kt`)
- **移除冗余标题**: 彻底取消了原先多余的 `“关联自：MEMO ▶”` 与 `“反向关联：MEMO ▶”` 文本行，直接以极简的灰色引用行输出：
  - `[↖ 灰底圆徽标]` `关联笔记内容...`
- **字号与粗细精准调校**:
  - **正文字号**: `15.sp`，行高 `22.sp`，字重 `Normal`，字体颜色 `#2C2C2E`（消除文字过大或过粗的感觉）；
  - **时间戳**: `12.sp`，颜色 `#9E9E9E`，字重 `Normal`；
  - **展开全文/收起**: `12.sp`，浅蓝色 `#4C88FF`；
  - **卡片边距**: 卡片内边距调优为 `14dp`。
- **纯白无边框卡片**: 移除所有多余的卡片外边框描边（`border`），还原为 Flomo 1:1 的纯白圆角卡片（`Color.White` + `RoundedCornerShape(12.dp)`）自然衬托于淡灰底色（`#F7F8FA`）之上的清爽质感。

### 3. 🌐 上下文时间线徽标统一 (`NoteDetailBottomSheet.kt`)
- **焦点笔记**: 移除原彩色的 `🎯` Emoji，升级为与品牌色呼应的**绿色圆底微标**（`Box(15.dp, CircleShape, #00C853)` + 纯白内圆心点）；
- **上级引用 (反链)**: 替换为**深灰圆底 + 纯白矢量链接图标**（`Box(15.dp, CircleShape, #8E8E93)` + `Icon(Link)`）；
- **衍生提及 (出链)**: 替换为**深灰圆底 + 纯白斜向箭头图标**（`Box(15.dp, CircleShape, #8E8E93)` + `Icon(ArrowBack 45°)`）。

### 4. 📂 侧边栏 85% 比例宽度与高亮绿色入口 (`DrawerContent.kt`)
- **抽屉宽度动态比例**: 移除固定的 `310dp` 硬限制，设置为 `fillMaxWidth(0.85f)`，在不同尺寸的移动设备上均能保持约 85% 宽度，右侧留出约 15% 的半透明遮罩与底层主页留白；
- **个人数据统计**: 大号统计数字调整为 `22sp`（`FontWeight.SemiBold`，`#2C2C2E`），下方文字 `12sp` 浅灰（`笔记`、`标签`、`天`）；
- **“全部笔记”高光入口**: 1:1 还原 Flomo 标志性的 **鲜亮绿色圆角卡片**（`#00C853`），采用白色文字 `全部笔记` 搭配白色网格图标与右侧小箭头；
- **标签分组标题**: `置顶标签` 与 `全部标签` 小标题调整为淡雅小字（`11sp`，颜色 `#9E9E9E`）。

### 5. 📝 编辑弹窗高度稳定性重构 (`NoteEditorBottomSheet.kt`)
- **悬浮图层 (Overlay) 架构**: 将次级悬浮胶囊工具栏从占用文档流高度的 Column 容器中移出，重构为基于 `Box` 的**悬浮图层**（`align(Alignment.BottomStart).padding(bottom = 58.dp)`）；
- **高度平稳不抖动**: 点击 `...` 展开或收起格式工具栏时，弹窗高度保持绝对稳定，彻底消除向上突跳抖动的问题。
