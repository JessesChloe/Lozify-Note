## 📋 任务概述

本阶段系统性地完成了 Lozify 积压需求与产品体验升级（共 7 个核心大项）：
1. **🏷️ 侧边栏置顶标签持久化与管理 (Pinned Tags)**：
   - Room 数据库迁移从 V3 升至 V4（新增 `is_pinned` 与 `pin_order` 字段）；
   - 侧边栏新增“置顶标签”独立模块，支持长按/菜单快速置顶/取消置顶；
   - 标签编辑页 `TagEditScreen` 支持置顶状态切换。
2. **🖼️ 图片附件大图灯箱预览 (Image Lightbox Dialog)**：
   - 打造纯黑沉浸式多图全屏灯箱 `ImageLightboxDialog`；
   - 支持双击快速放大 (1.0x <-> 2.5x)、双指捏合缩放 (1.0x ~ 5.0x) 与边界拖动阻尼；
   - 支持 `HorizontalPager` 横向轻扫切换多张图片及顶部 `1 / N` 序号指示。
3. **🔍 搜索关键词高亮与段落自适应展开 (Search Highlighting)**：
   - `RichTextUtils.parseRichText` 支持传入 `searchQuery` 并计算明黄色背景与加粗的高亮区间；
   - 搜索状态下匹配卡片自动展开，防止关键内容被 5 行折叠截断。
4. **🔄 侧边栏“全部标签”排序与筛选 (Tag Search & Sorting)**：
   - 侧边栏增加 36dp 实时胶囊过滤框；
   - 提供按使用频次、字母 A-Z / 字典序、最新创建时间 3 种排序模式。
5. **ℹ️ 侧边栏帮助中心与常见问题指引 (Help Center & FAQ)**：
   - 新建独立 `HelpCenterScreen` 页面与 `Routes.HELP` 路由；
   - 呈现排版语法、智能输入拦截、网状双链、灯箱手势以及 100% 离线隐私保护五大指南。
6. **💾 本地数据全量备份与导入导出 (Backup & Restore)**：
   - 核心备份引擎 `BackupManager`：导出全量 JSON 备份（含正文、时间戳、置顶状态、标签与 `@mention` 双链）；
   - 导出 Markdown ZIP 压缩包（每条笔记带 YAML 标头，兼容 Obsidian / Logseq）；
   - 独立 `BackupRestoreScreen` 页面，支持 Android SAF 文件选择器及增量合并导入恢复。
7. **🧪 自动化测试套件补充 (Unit Testing Suite)**：
   - 编写 `RichTextUtilsTest`、`SmartInputFilterTest`、`TagSortAndFilterTest`、`BackupJsonTest` 等 17 项单元测试，100% 通过。

## 🛠️ 完成的功能与架构改造

### 1. 数据库升级 (`LozifyDatabase.kt`, `TagDao.kt`, `TagEntity.kt`)
- `MIGRATION_3_4`：
  ```sql
  ALTER TABLE tags ADD COLUMN is_pinned INTEGER NOT NULL DEFAULT 0;
  ALTER TABLE tags ADD COLUMN pin_order INTEGER NOT NULL DEFAULT 0;
  ```
- `TagDao` 新增 `getPinnedTags()`、`updatePinStatus()`、`updatePinOrder()` 查询方法。

### 2. 图片大图灯箱 (`ImageLightboxDialog.kt`)
- 基于 `Dialog(properties = DialogProperties(usePlatformDefaultWidth = false))` 实现全屏纯黑沉浸视图。
- 组合手势检测：双击重置/放大、双指捏合 `detectTransformGestures`、平移位置根据当前缩放比例限定边界。

### 3. 数据备份与恢复 (`BackupManager.kt`, `BackupRestoreScreen.kt`)
- **JSON 序列化与反序列化**：无损存储全量标签、笔记与双链引用；
- **Markdown 打包**：`ZipOutputStream` 打包带有 YAML Frontmatter 的 `.md` 文件；
- **增量合并导入**：基于名称匹配既有标签，新标签自动入库，笔记重新关联 `NoteTagCrossRef`。

### 4. 自动化测试套件 (`app/src/test/java/`)
- 全套 17 个 JVM 单元测试覆盖富文本、输入拦截器、标签算法与 JSON 校验，运行 `gradlew testDebugUnitTest` 全部 PASSED。
