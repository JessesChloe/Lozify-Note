# 开发日志 - 2026-08-19 (阶段 27：WebDAV 端到端数据加密与抗审查防和谐系统)

## 📋 阶段概述
针对国内网盘（如坚果云等）可能对用户云端同步的图文附件进行内容扫描审查、误杀或和谐封锁的痛点，设计并实现了基于 **AES-256-GCM 硬件加速认证加密与 PBKDF2 密钥派生** 的 **端到端加密体系 (E2EE - End-to-End Encryption)**。
在数据离开手机前，全量转换为不可读的高熵二进制密文 (`.enc`)，彻底抹除原始图片与文字特征，从数学底层 100% 免疫网盘服务端内容扫描与审查，同时与本地 Markdown 明文导出形成二元清晰分立。

---

## 🛠️ 完成内容详解

### 1. 🛡️ 硬件级 AES-256-GCM 端到端加密引擎 (`CryptoUtils.kt`)
- **零第三方依赖**: 基于 Android 原生 `javax.crypto` 与 `java.security` 实现硬件级指令加速，单张图片加解密 `<1ms`；
- **密钥派生 (KDF)**: 用户自定义主密码通过 `PBKDF2WithHmacSHA256` 算法（10,000 次迭代计算 + 16 字节高安全性随机 Salt）派生 256 位 AES 密钥；
- **密文信封格式 (`.enc`)**:
  ```
  [4B Magic Header: "LZNC"] + [1B Version: 0x01] + [16B Salt] + [12B GCM IV] + [Ciphertext + 16B GCM Auth Tag]
  ```
- **防篡改与完整性校验**: AES-GCM 认证加密 (AEAD) 自带数据签名，任何密文损坏或错误密码均会触发校验异常并友好拦截。

### 2. ⚡ WebDAV 双向同步引擎加密适配 (`WebDavSyncManager.kt`)
- **结构化 Payload 加密**:
  - 开启加密时，将结构化笔记/标签 JSON 序列化并加密为 `notes_payload.json.enc`；
  - 云端拉取时在本地内存中实时解密并校验密码；
- **图文附件差异池加密流**:
  - 本地图片 `img_xxx.jpg` 上传时流式加密为 `img_xxx.jpg.enc`，网盘服务端完全无法探测图片头部特征；
  - 远端拉取图片密文时，在本地沙盒流式解密还原为标准图片；
- **Manifest 元数据标记**:
  - 记录 `isEncrypted: true` 与设备信息，密码绝不上传云端，保障零知识隐私安全性。

### 3. 📱 表现层配置与安全指引 (`WebDavSyncScreen.kt` & `WebDavSyncViewModel.kt`)
- **【端到端隐私加密 (E2EE)】卡片**:

  - 同步加密主密码（Sync Passphrase）输入框，支持明暗文切换与实时持久化；
  - 醒目的安全提示与“为什么能彻底防和谐”原理说明卡片。
