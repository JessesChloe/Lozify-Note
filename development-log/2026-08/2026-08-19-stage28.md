# 开发日志 - 2026-08-19 (阶段 28：Gitee / GitHub 双通道国内极速在线版本检测与更新推送系统)

## 📋 阶段概述
为解决国内网络环境下直接访问 GitHub 经常出现的高延迟、DNS 污染与连接超时问题，设计并实现了 **Gitee（码云）首选 + GitHub / CDN 备用容灾** 的双通道在线版本检测与应用内更新推送系统。
无需任何自建服务器运维开销，即可通过静态 `version.json` 或 Releases 节点，向所有已安装软件的用户秒级推送最新版本日志、新特性说明与极速下载安装指引。

---

## 🛠️ 完成内容详解

### 1. ⚡ Gitee + GitHub 双通道容灾版本检测引擎 (`UpdateManager.kt`)
- **国内极速优先**: 默认首选 Gitee 镜像源（国内网络访问延迟通常 `<200ms`，无需科学上网）；
- **无感容灾回退**: 若 Gitee 节点偶发异常或不可达，客户端将在 5s 超时内自动静默切换请求 GitHub / CDN 备用源；
- **智能版本比对**: 精准比对远程 `versionCode` 与本地当前构建版本号，支持语义化版本名 (`SemVer`) 与强制更新 (`isForceUpdate`) 标记解析。

### 2. 📱 拟态质感更新卡片弹窗 (`AppUpdateDialog.kt`)
- **视觉设计**: 采用 Lozify 专属活力绿火箭徽标与拟态圆角卡片布局；
- **信息呈现**: 醒目展示新版本号、发布日期与富文本更新日志（支持长列表平滑滚动）；
- **一键下载动作**:
  - 【立即更新 (国内 Gitee 极速源)】：一键直链高速拉取 APK 安装包；
  - 【GitHub 备用源下载】：提供多线路下载选择；
  - 【稍后提醒】：非强制更新时优雅关闭。

### 3. ⚙️ 设置中心无缝集成 (`SettingsScreen.kt` & `SettingsViewModel.kt`)
- **交互升级**: 将静态版本行升级为带点击波纹、加载动画与即时反馈的【检查新版本】交互入口；
- **状态感知**:
  - 检查中：显示微型旋转进度环；
  - 最新版本：弹出轻量级 Snackbar 提示 *“已是最新版本 (v1.2.0)”*；
  - 发现新版：直接弹出 `AppUpdateDialog` 并展示完整的更新说明。
