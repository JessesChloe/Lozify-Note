## 📋 任务概述

### 主要目标
1. **Flomo 风格卡片富文本操作菜单 (`NoteCard.kt`)**：
   - 将原单列简陋的 `DropdownMenu` 重构为高信息密度的卡片操作面板。
   - 顶部快捷操作栏：【复制】、【编辑】、【删除】（横向等分，图上文下，支持剪贴板一键复制并 Toast 提示，删除采用醒目红色预警）。
   - 中间功能项：【设为置顶 / 取消置顶】。
   - 底部元数据面板：展示字数统计与创建时间（浅灰底色、11sp 灰色辅助字）。
2. **侧边栏成就面板 / 个人数据中心 (`DrawerContent.kt`, `HomeViewModel.kt`, `UserStats.kt`)**：
   - 在侧边栏顶部新增用户记录里程碑面板。
   - 实时统计并展示三大核心数据：**笔记数**、**标签数**、**记录天数**（根据首条笔记创建时间计算距今天数）。
   - 顶部 3 列等分网格，24sp 加粗大数值 + 12sp 辅助文字，并用 `HorizontalDivider` 与标签列表隔开。

## 🛠️ 完成的功能与架构改造

### 1. 卡片富文本操作菜单 (`NoteCard.kt`)
- **顶部快捷操作栏 (Row)**：
  - 复制：调用 `LocalClipboardManager.setText(AnnotatedString(content))` 并弹出 Toast 提示。
  - 编辑：触发 `onEditClick` 回调。
  - 删除：使用 `MaterialTheme.colorScheme.error` 红色字体，触发 `onDeleteClick` 回调。
- **中间项**：保持原有的置顶状态切换 `onTogglePinClick`。
- **底部面板 (Column)**：
  - 背景色：`Color(0xFFF9F9F9)`。
  - 字数统计：`${content.length}`。
  - 创建时间：`${timestamp}`。
- **视觉宽度**：将菜单固定为 `Modifier.width(220.dp)`，保障横向三列操作排版舒适。

### 2. 侧边栏成就面板 (`UserStats.kt`, `HomeViewModel.kt`, `DrawerContent.kt`)
- **`UserStats.kt` (Domain Model)**：
  ```kotlin
  data class UserStats(
      val notesCount: Int = 0,
      val tagsCount: Int = 0,
      val daysCount: Int = 1
  )
  ```
- **`HomeViewModel.kt` (Data Layer)**：
  - `userStats: StateFlow<UserStats>` 与 `HomeUiState.userStats`。
  - 利用 `allNotes.minOfOrNull { it.createdAt }` 结合 `java.time.temporal.ChronoUnit.DAYS` 动态计算使用天数。
- **`DrawerContent.kt` & `HomeScreen.kt` (UI Layer)**：
  - 在 `DrawerHeader` 紧随其后插入 `DrawerStatsPanel`。
  - 每项使用 `DrawerStatItem` 垂直居中展示（24sp Bold 数值 + 12sp 浅灰描述）。
  - 下方使用 1dp `HorizontalDivider` 与标签列表清晰分割。
